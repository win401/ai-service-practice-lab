# known_faces 폴더

이 폴더에 인식할 축구 선수 사진을 넣으면 앱 실행 시 자동으로 등록됩니다.

## 파일 이름 규칙

파일 이름(확장자 제외)이 선수 이름으로 표시됩니다.

```
known_faces/
  손흥민.jpg
  이강인.jpg
  황희찬.png
  김민재.jpg
```

## 주의사항

- 얼굴이 선명하게 나온 정면 사진 1장이면 충분합니다.
- 지원 형식: jpg, jpeg, png
- 사진 1장당 얼굴 1개만 있는 이미지를 권장합니다.
- 여러 장을 넣으면 가장 처음 감지된 얼굴을 사용합니다.

## tolerance 설정

앱의 `얼굴 인식 민감도(tolerance)` 슬라이더로 조절합니다.
- 값이 낮을수록 엄격하게 비교 (오인식 줄어듦, 미인식 늘어남)
- 값이 높을수록 유연하게 비교 (미인식 줄어듦, 오인식 늘어남)
- 기본값: 0.55
